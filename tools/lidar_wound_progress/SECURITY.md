# Security and privacy

This is research software, not a clinical system. Do not commit patient data,
identifiers, screenshots, device captures, access tokens, or production
credentials. Use the synthetic manifest as the default test input.

If you find a security or privacy issue in this folder, do not publish sensitive
details in a public issue. Contact the repository owner through the repository's
private communication channel and include a minimal reproduction without
protected health information.

The tool has no network client, cloud dependency, authentication layer, or
persistent database. A future sensor adapter must define capture retention,
access control, encryption, audit, deletion, and consent requirements before
handling clinical data.
