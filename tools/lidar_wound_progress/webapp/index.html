How the comparison works

Depthline uses calibrated digital planimetry measures—area, perimeter, longest/widest dimensions—and reports percentage area reduction alongside linear edge change. The image signal uses a structural-similarity calculation as a comparability aid. See WOUND_COMPARISON_METHOD.md in the repository for references and limitations. True device depth remains available through the native ARCore/ARKit adapters and depth-grid workflow.
