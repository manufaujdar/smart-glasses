# Documentation index

Smart Glasses is an Android-first, vendor-neutral healthcare smart-glasses
research and prototyping workspace. Its executable baseline is synthetic/local;
the Android/HeyCyan boundary and physical-device validation remain gated.

## Authoritative documents

- README.md and docs/00-project-overview.md: scope and entry path.
- docs/architecture/: system/data-zone and code organization.
- docs/security/: threat model.
- docs/product/, docs/surgery/: product and clinical research scope.
- docs/testing/: hardware validation plan.
- docs/protocols/ and packages/*/README.md: device/workflow contracts.
- third_party/: provenance and license records.
- docs/technical-overview.md: code and technology baseline.
