Integration method

What connects now—and what still needs hardware

Fieldline is a vendor-neutral local control plane. The simulator runs end to end; physical devices connect only through an explicitly configured Android or vendor bridge.

Implemented now

  • Adapter discovery, selection and one-owner connection lifecycle.
  • Capability-gated photo, preview, video, audio, live-stream state, battery/version and media metadata commands.
  • Idempotent command IDs, bounded events, WebSocket state updates and disconnect safe-stop.
  • Browser/phone camera and microphone preview, local snapshot and local recording download.
  • Push-to-talk exact voice allowlist with confirmation for capture and start commands.

Adapter paths

  • HeyCyan: licensed SDK bridge for advertised BLE capture/status and Wi-Fi media workflows. No proprietary binary or guessed packet implementation is included.
  • MentraOS: external Bluetooth SDK bridge with per-device capability negotiation.
  • Brilliant Frame: external BLE/Lua SDK bridge for its distinct display/camera interaction model.
  • LiveKit: recommended optional Android WebRTC sink after identity, token, TURN, encryption, recording and retention policy review.

Not demonstrated

  • Physical HeyCyan discovery, pairing, firmware compatibility or media transfer until an authorized SDK and test device are supplied.
  • A glasses live preview where the selected device/SDK does not declare it.
  • Production speech recognition, AI inference, security/privacy suitability for patient data, clinical benefit or regulatory compliance.
