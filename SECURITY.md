# Security and safety policy

This repository is a research prototype, not a clinical device. Never commit
device identifiers, recordings, patient information, credentials, or proprietary
SDK material.

Report suspected security or safety issues privately using GitHub
[Security Advisories](https://github.com/manufaujdar/smart-glasses/security/advisories/new)
when available. Include a minimal synthetic reproduction. Do not publish
exploitable device details, credentials, patient data, or private captures in a
public issue.

Disconnect, interruption, capability mismatch, capture-indicator failure,
privacy exposure, command replay, unsafe model behavior, and misleading
hardware or clinical claims are release-blocking concerns. Public source
availability does not imply a security SLA, HIPAA compliance, clinical
suitability, or a warranty.
